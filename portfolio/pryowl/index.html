Pryowl

Pryowl is a modern survey & form-builder SaaS. Authors design surveys in a visual builder with genuinely advanced logic — conditional show/hide, skip/branching, and matrix grids — then publish them with intelligent gating: response caps, save-and-resume, and one-per-browser/email limits.

A workspace model with fine-grained RBAC (21+ granular permissions) lets teams collaborate, while every response is stored as an immutable snapshot of the survey at submission time. Built with React + Vite + TypeScript on Supabase, with per-workspace branding, dark mode and EN/FR support.

Key features:
  • Visual survey builder with instant preview
  • Conditional logic (show / hide by answer)
  • Skip logic / branching
  • Matrix (grid) questions
  • Response caps & one-per-browser/email limits
  • Save & resume from browser
  • Workspace RBAC v2 with custom roles & 21+ permissions
  • Team workspaces with invites
  • Per-workspace branding (colours, logos)
  • Rich question types (text, rating/stars, phone, date, multiselect, matrix)
  • Immutable response snapshots
  • Analytics dashboard (Recharts) + CSV / PDF export
  • Multi-language (EN / FR) + dark mode
