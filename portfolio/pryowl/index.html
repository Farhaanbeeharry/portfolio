Pryowl

June 2026 Farhaan Beeharry
web app saas survey builder quiz e-signature react supabase
Pryowl started as a survey builder and grew into a full data-collection and document platform. Authors design forms in a visual builder with genuinely advanced logic, publish them with intelligent gating, auto-mark them as quizzes, analyse the results across nine chart types — and, in the same workspace, send PDFs out for legally-structured e-signature.

Inside it lives Hoot, the owl — an AI copilot you talk to in a chat. Describe what you want to ask and Hoot returns a complete survey (title, questions, options, settings), then keeps editing as you refine, and names exactly what it changed each turn. It knows every question type in the builder and answers in one of eight selectable tones, in English or French.

The builder covers 21 question types — short and long answer, e-mail, number, phone, date, time, single and multiple choice, dropdown, yes/no, consent, star rating, linear scale, NPS, matrix grids, section breaks, image upload, image URL, link and file upload. Questions can show or hide on earlier answers (conditional logic), jump respondents forward (skip logic / branching), and be grouped into sections with their own progress.

Turning a survey into a quiz is a setting, not a different product. Correct answers are stored per question and — critically — never sent to the browser: the public fetch omits the column entirely and grading happens inside a server-side function, so the answer key cannot be scraped from the page. Authors can optionally show respondents their score with a pass mark, and mark free-text answers by hand afterwards.

A workspace model with fine-grained RBAC (24 permissions) lets teams collaborate, and the scoped permissions are tri-state rather than boolean — None / Own / All — so a member can be allowed to edit their own surveys but only view everyone else's. The permission engine also enforces implications: granting "publish own surveys" silently raises "view own surveys", because the first is meaningless without the second. Every rule is re-enforced in Postgres Row Level Security and database triggers, not just in the UI.

Every response is stored as an immutable snapshot of the survey at submission time, so editing a question later never rewrites history or corrupts old analytics.

Building
  • Visual builder with instant preview and drag-ordered questions
  • 21 question types, including matrix grids, NPS, consent and file upload
  • Conditional logic — show / hide a question by earlier answers
  • Skip logic and branching
  • Sections with their own titles and progress
  • Hoot, the AI copilot — builds and edits a whole survey in chat
  • Eight selectable Hoot reply tones
  • Reusable survey templates
  • Per-workspace branding — colours, logos, custom start screen

Publishing & responding
  • Response caps that close a survey automatically
  • One-per-browser and one-per-e-mail submission limits
  • Save & resume a part-finished response from the browser
  • Invite respondents by e-mail from inside the app
  • Anonymous responses when the survey allows it
  • Attempt timers, with a clear notice when time is capped
  • Cancel a live survey without destroying its responses
  • A "my responses" area where a respondent can find their own submissions

Quizzes & marking
  • Per-question correct answers, never exposed to the client
  • Server-side auto-grading with score and max score
  • Optional score reveal with a configurable pass mark
  • Manual marking of free-text answers, with custom mark values
  • Detailed per-question results and a results message per outcome

E-signature
  • Upload a PDF and place signature, text and date fields on it
  • Visual document builder rendering the real PDF on canvas
  • Draw-to-sign signature pad
  • Send a document out for signing and track its status
  • A signed copy written back into the PDF with pdf-lib
  • Document library with view / update / delete permissions

Analysis
  • Nine chart types — bar, stacked bar, line, pie, polar area, radar, gauge, data table and a chart-type picker per question
  • Per-question summaries and cross-response analytics
  • Individual response inspection
  • CSV and PDF export

Workspaces, accounts & platform
  • Team workspaces with e-mail invitations and an accept-invite flow
  • Custom roles built from 24 permissions, scoped None / Own / All
  • Permission implications enforced so a role can never be incoherent
  • Ownership transfer, workspace icon / colour / logo picker
  • Two-factor authentication, OTP verification and OTP password reset
  • Plan tiers (Free / Pro / Business) with workspace and survey limits enforced by database triggers
  • In-app notifications
  • Marketing site — features, pricing, comparison, e-signature and Hoot pages
  • Multi-language (EN / FR) and dark mode, both driven by CSS custom properties
