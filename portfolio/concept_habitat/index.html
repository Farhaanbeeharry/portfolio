Concept Habitat CRM

Concept Habitat "After Hours" is a staff-only CRM and visitor-registration system built for an exclusive home & lifestyle showroom event in Mauritius. A public form captures visitor profiles — with photo and PDF attachments — while staff log in to a dark, luxury dashboard to score leads, run a follow-up pipeline and export insights.

Role-based access (Super Admin / Admin / Staff) is enforced with Supabase Row-Level Security, so every user sees only what their role allows. Built with React + Vite and deployed on Vercel, the tool turns a single evening of walk-in guests into a clean, measurable sales pipeline.

Key features:
  • Custom registration form builder with conditional field visibility
  • Role-based access (RLS: Super Admin / Admin / Staff)
  • Executive dashboard with live KPIs and 7-day trend
  • Searchable / filterable visitors table with bulk CSV & XLSX export
  • Hot / warm high-priority leads board
  • Kanban follow-up pipeline (Not Contacted → Contacted → Quotation Sent → Won / Lost)
  • Visitor profiles with timestamped notes & attachments
  • Performance analytics (conversion rate, top products, staff ranking)
  • Field-level audit log
  • OTP password reset
  • Soft-delete / archive with restore
