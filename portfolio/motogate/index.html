MotoGate

Built for MotoClub Mauritius, MotoGate is a custom event access-management app that replaces manual guest lists with secure QR ticketing and live gate control. It runs the full lifecycle of a motorsport or VIP event — creating the event, building the guest list, issuing passes, and scanning people in at the gate against a live database.

On the organiser side it is a control room. Admins create an event, set venue capacity, and manage invitees, their companions and whole teams — each assigned an access role that decides where they can go. Roles are not hard-coded: the seven system defaults (Media, Staff, VIP, Sponsor, Services, Demo, Other) can be renamed, recoloured, re-iconed, disabled or joined by custom roles of the club's own. Passes are issued as QR codes, printable on-site as access bracelets, and every scan, override and exceptional admission lands in a live entry log.

At the gate, scanning is built for speed and trust. Each code is verified live against Cloud Firestore for event ownership, validity and re-use, then a full-screen result shows access granted or denied, admits the allowed number of companions, and offers a supervised override for edge cases. A separate special guest entry flow covers people who arrive without a pass at all.

The same QR format doubles as a MotoClub racing licence, so event invitations and competitor IDs run through one pipeline. Licences have their own lifecycle — application, review, issue, renewal — and the admin console filters them by Pending, In Review, Issued, Renewals, Rejected and Revoked. Attendee passes are protected against screenshots and screen recording, and auto-boost screen brightness so they scan first time.

Access to the console itself is permission-gated. A super-admin grants any combination of seven staff permissions — event admin, licence admin, user management, QR scanning, notifications, pricing and manual account verification — so a gate steward sees only the scanner while the club secretary sees the licence queue.

Events & guests
  • Event creation and editing with venue capacity management
  • Live / upcoming / past event states, with a single live event at a time
  • Invitee, companion and team registration
  • Contact-book import when adding guests, so numbers are not retyped
  • Customisable access roles — name, colour, icon, enabled state
  • Companions directory reused across events
  • Sponsor management

Ticketing & the gate
  • QR pass generation, viewable in-app and shareable
  • Camera scanning with live Firestore verification
  • Re-use, wrong-event and invalid-code rejection
  • Companion admission counted against the invitee
  • Supervised override flow for exceptional cases
  • Special guest entry for unticketed arrivals
  • Live entry log and audit trail of every decision
  • On-device PDF generation for printed access bracelets
  • Data export as CSV or PDF, via share sheet or file download

Racing licences
  • Licence application and renewal from the member's own phone
  • Admin review queue with issue / reject / revoke decisions
  • Status filters — Pending, In Review, Issued, Renewals, Rejected, Revoked
  • Document and photo upload with in-app image cropping
  • The licence QR is the same format as an event pass
  • Configurable pricing per licence type

Accounts, staff & platform
  • Sign-up and login by e-mail or mobile number
  • 6-digit OTP verification and OTP-based password reset
  • Manual account verification flow for members without documents
  • Seven granular staff permissions granted by a super-admin
  • Users directory and staff management console
  • Broadcast push notifications to invitees, plus local notifications
  • Screenshot / screen-recording protection on passes
  • Automatic screen-brightness boost while a pass is displayed
  • Published on both the Google Play Store and the Apple App Store
